  rooms, agents, task state and SQLite recovery paths.

  coordinates, 200 substantive prompt role templates and strict integration
  provenance validation.

  records, and byte-pinned SHA-256 read review.
- Exercised Windows private-desktop GUI snapshots and Linux `.deb`/AppImage
  native Xvfb packaging in a controlled environment; source and package hashes
  live under `docs/qa/` and `docs/release/`.
- Added explicit acceptance and CI lockfile records. There is no configured
  Git remote, signed public release or completed cross-platform matrix.
