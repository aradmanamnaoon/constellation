## Release rule

The user requested locally tested Windows/macOS/Linux/Android deliverables and subsequently elected to **replace the hosted GitHub Actions tests with local execution** where practical. The exact local CI results and resource safety stops are recorded in `local-ci-replacement-20261102.md`. A Windows host still cannot execute genuine macOS Intel/ARM64 native tests, and Android production packaging, consent/Keystore/checkpoint support and installed-device acceptance remain incomplete. GitHub Actions annotations separately report account payment or Actions spending-limit failures before any job starts; **local success must not be labeled a successful hosted run**. Do not create an apparently complete release or relabel a stale/debug artifact to disguise this. Existing `v0.1.2-local-desktop-preview-20261101` remains a separate, clearly marked preview.
